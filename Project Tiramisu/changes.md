# Project Remixer & Delta Engine (`changes.md`)

> **Creator**: Harshit (wl2sa) — 12-Year-Old Architect from India 🇮🇳

---

## ✅ What this file DOES
1. **Drives Project Remixing**: Used when you are inspired by an existing website, GitHub repository, or UI template and want the AI to adapt it for your own project.
2. **Defines "What to Keep vs. What to Replace"**: Clearly separates what structure to borrow from the inspiration (e.g. navigation layout, grid) from what personal branding, colors, and data to substitute.
3. **Prevents Accidental Plagiarism**: Directs the AI to strip out proprietary logos, copyright notices, and specific API keys from the source.

---

## 🛑 What this file DOES NOT do
1. **Does NOT apply to projects built from scratch**: If you are creating a completely new concept with no external inspiration, leave this file empty or skip it.
2. **Does NOT store active session tasks**: Write your immediate assignment in `prompt.md`.
3. **Does NOT contain permanent rules**: Security laws belong in `rules.md`.

---

## 💡 Practical Real-World Example

```markdown
### 🎨 Inspiration Source
- **Inspiration URL**: https://linear.app
- **Inspiration Name**: Linear Product Homepage
- **Core Aesthetic to Adopt**: Ultra-clean dark theme with keyboard shortcuts and crisp card borders.

### ✂️ What to Keep vs. What to Replace

| Dimension | Keep from Linear Inspiration | Replace with User Details |
| :--- | :--- | :--- |
| **Branding** | Clean header navigation layout | Replace with "Project Tiramisu" logo & name |
| **Color Scheme** | High-contrast dark void background | Replace accents with custom palette from design.md |
| **Content** | Punchy headline and benefit layout | Replace with actual framework documentation & copy |
| **Integrations** | Modal keyboard shortcut popup | Connect to Tiramisu layer search rather than issue tracker |
| **Assets** | Bento grid layout ratios | Replace screenshots with Tiramisu code examples |
```
