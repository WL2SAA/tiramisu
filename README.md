## 📖 What is Project Tiramisu?

Just like the beloved Italian dessert is constructed with harmonious layers — espresso-soaked ladyfingers, velvety mascarpone cream, and dark cocoa dust — **Project Tiramisu** deconstructs AI software development context into clean, decoupled, modular markdown layers.

Large language models suffer from **context contamination** and **hallucination** when prompted with massive, tangled instruction sets. Furthermore, low-cost/budget models (like Gemini Flash, Claude Haiku, GPT-4o-mini, or local 7B/8B models) often fail when instructed with abstract design concepts. 

Project Tiramisu solves this with a structured directory of specialized files that guide any AI model step-by-step.

## ⚡ 1-Command Installation & Scaffolding

Scaffold Project Tiramisu instantly into any new or existing repository:

### Option A: Python 3 (Cross-Platform)
```bash
python init.py --name "My Project" --style "Bento Grid"
```

### Option B: PowerShell (Windows)
```powershell
.\init.ps1 -ProjectName "My Project"
```

### Option C: Git Clone
```bash
git clone https://github.com/WL2SAA/tiramisu.git
```

## 🗂️ The Tiramisu Layer Stack

| File | Layer | Primary Function |
| :--- | :--- | :--- |
| [`howto.md`](Project%20Tiramisu/howto.md) | **Orchestrator** | Master guide instructing the AI on the reading sequence and operational lifecycle. |
| [`prompt.md`](Project%20Tiramisu/prompt.md) | **Directive** | Current session task, objectives, and acceptance criteria set by the user. |
| [`rules.md`](Project%20Tiramisu/rules.md) | **Guardrails** | Non-negotiable laws: security, accessibility, clean code, dos and don'ts. |
| [`agents.md`](Project%20Tiramisu/agents.md) | **Multi-Agent** | Defines specialized personas (`@architect`, `@designer`, `@systems`, `@auditor`, `@scribe`). |
| [`antigravity.md`](Project%20Tiramisu/antigravity.md) | **Agentic Autonomy** | Secondary roles, self-healing sentinel protocols, and Antigravity tool rules. |
| [`CLAUDE.md`](Project%20Tiramisu/CLAUDE.md) | **Claude Adaptor** | Quick commands, conventions, and style rules for Anthropic's Claude Code CLI. |
| [`GEMINI.MD`](Project%20Tiramisu/GEMINI.MD) | **Gemini Adaptor** | Context handling, 1M+ token strategies, and deep reasoning directives for Google Gemini. |
| [`changes.md`](Project%20Tiramisu/changes.md) | **Remixer Engine** | Delta instructions when remixing/forking inspired projects ("What to keep vs. replace"). |
| [`design.md`](Project%20Tiramisu/design.md) | **Visual Blueprint** | Project-specific theme, hex colors, typography scale, and component rules. |
| [`design-style.md`](Project%20Tiramisu/design-style.md) | **Style Dictionary** | Bridges low-cost models with concrete CSS/Tailwind tokens for Minimalist, Bento, Brutalism, etc. |
| [`analysis.md`](Project%20Tiramisu/analysis.md) | **Audit & Health** | Architectural audit, codebase structure, dependency reviews, and benchmarks. |
| [`source.md`](Project%20Tiramisu/source.md) | **Asset Registry** | External inspirations, documentation links, icon sets, and creator references. |
| [`usage.md`](Project%20Tiramisu/usage.md) | **Human Manual** | Step-by-step guide for developers on how to adopt Project Tiramisu in any repo. |
| [`plans/plan01.md`](Project%20Tiramisu/plans/plan01.md) | **Execution Tracker**| Granular task checklist and milestone progression tracker. |
